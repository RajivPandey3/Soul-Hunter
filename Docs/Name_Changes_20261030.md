# Display names: VS names replaced (owner-approved 2026-10-30)

Owner, release audit question 1: "Sirf VS naam badlo". Then "Haan, ye list lagao" for this list.

Only the name a player sees changes. Code ids, enum values, asset file names, the save and every mechanic stay as they are, so old saves load with no migration. Names that are ordinary English words stay the same: Whip, Knife, Axe, Cross, Garlic, Fire Wand, Magic Wand, Lightning Ring, Gun, Bone, Cherry Bomb, Pentagram, Laurel, Bible, Spinach, Wings, Crown, Clover, Bracer, and the Awake and Gemini Arcanas.
