# Agent capabilities

| Role | Authorized responsibility | Boundary |
|---|---|---|
| Bootstrap auditor | Read repository/environment; add approved governance documents | No gameplay changes or acceptance inflation |
| Planner | Produce bounded tasks and traceable criteria | Cannot weaken requirements or self-authorize scope |
| Implementer | Execute explicitly authorized task in allowed paths | Cannot alter protected tests/governance or self-accept |
| Validator | Reproduce tests, record artifacts and failure classification | Test success alone cannot grant final PASS |
| Reviewer / CTO owner | Review risk, coverage and evidence; recommend acceptance | Must identify missing independent evidence |
| Release operator | Authorized checkpoints/build/release | No implicit commit, push or deployment permission |

Observed tools: Windows PowerShell, Git, Python and Unity CLI. Unity status responds; a main-thread read query timed out. This is not evidence of an unattended reliable tool loop.

No sub-agents were used. Model-specific capability/performance was not benchmarked. Do not assume an Astra/Sol/Luna allocation or spend high reasoning on speculative implementation. Delegate only when explicitly authorized and concrete independent work justifies it.

No scheduler, task runner, role isolation or permission enforcement was installed. These directories describe responsibilities, not a functioning autonomous system.
